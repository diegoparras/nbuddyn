# Code of conduct

nbuddyn follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and talk about the work, not the person.
Harassment, insults and discrimination of any kind are not welcome here, in issues, pull
requests or anywhere else the project lives.

If someone's behaviour worries you, write to the maintainer through
[GitHub](https://github.com/diegoparras). Reports are kept private.
